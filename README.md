# 📚 Student Task Manager

A lightweight, responsive web application designed for students to organize assignments, track course deadlines, and manage daily study tasks efficiently. Built using HTML5, modern CSS3, and vanilla JavaScript with zero external library dependencies.

---

## ✨ Features

* **Task Management**: Add, complete, and delete tasks in real-time.
* **Priority Badging**: Color-coded badges for **Low**, **Medium**, and **High** priority items.
* **Subject Tagging & Due Dates**: Categorize tasks by academic subject and assign target deadlines.
* **Live Statistics Dashboard**: Track real-time counts for Total, Pending, and Completed tasks.
* **Local Storage Persistence**: All tasks auto-save to browser local storage so your data remains saved across sessions.
* **Filter Views**: Easily filter tasks by *All*, *Pending*, or *Completed*.
* **Responsive Apple-Inspired UI**: Minimalist, card-based interface optimized for desktop and mobile devices.

---

## 🛠️ Tech Stack

* **HTML5**: Semantic layout and form control elements.
* **CSS3**: Custom properties (CSS variables), Flexbox, CSS Grid, and custom interactive elements.
* **JavaScript (ES6+)**: Dynamic DOM manipulation, event handling, and Browser `localStorage` API.
